## 三、個人問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

* **計費原因**：因為 `" Amy"` 與 `"amy"` 統一轉小寫並去除空白後皆為 `"amy"`，屬於同一個人在同一場活動重複報名。根據規則，同一人在同一場活動只算一位參加者並只收一次費用，因此實際不重複參加者為 `amy`、`ben`、`cora` 共 3 人，費用為 `3 × 120 = 360` 元。
* **結構差異**：
  * **直接拆成 `list`**：**保留了**原始報名的先後順序以及重複報名的次數紀錄；但**失去了**唯一性（無法直接得知實際不重複人數，也無法直接進行集合比對）。
  * **再轉成 `set`**：**保留了**不重複的參加者名單（唯一性）以及快速進行交集、聯集、差集運算的能力；但**失去了**原本的報名先後順序（集合是無序的）以及重複報名的次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

* **集合關係說明**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。兩者的聯集 $A \cup B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，元素個數 $|A \cup B| = 3$，代表「總不重複人數」為 3 人；同時兩者的交集 $A \cap B$ 也是這 3 人，代表這 3 個人同時報名了兩場活動。
* **算式說明**：
  * **報名人次**：計算方式為兩場各自去重後的人數相加，即 $|A| + |B| = 3 + 3 = 6$ 人次（每人參加兩場，各自貢獻 2 人次）。
  * **總應收金額**：兩場活動分開計費，桌遊應收為 $3 \times 120 = 360$ 元，電影應收為 $3 \times 80 = 240$ 元，兩者相加 $360 + 240 = 600$ 元。
